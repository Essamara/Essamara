# Batch Quantum-Anchored Provenance (`filetagbatch.py`)

This script generates a comprehensive provenance report for a directory of files, securing the integrity of the entire report with a single, quantum-resistant hash anchor.

## Description

This script provides a powerful tool for data security and integrity verification. It recursively scans a specified directory, calculates the SHA256 hash of each file, and compiles all of this information into a single JSON manifest file.

The key feature of this script is the "quantum anchor": a root hash generated by a quantum random number generator (as demonstrated in `shake.py`). By including this hash in the report's metadata, the integrity of the entire manifest is cryptographically secured against both classical and future quantum attacks.

## How It Works

1.  **Directory Scan**: The script traverses the specified root directory and all of its subdirectories.
2.  **File Hashing**: For each file found, it calculates a standard SHA256 hash.
3.  **Manifest Generation**: It creates a detailed JSON object containing:
    -   Report metadata, including a timestamp and the crucial quantum anchor hash.
    -   A list of records for each file, including its name, path, size, and SHA256 hash.
4.  **Report Saving**: The final JSON manifest is saved to an output file.

## Dependencies

- **Python 3.x**

## How to Run

1.  **Configure the Root Directory**:
    -   By default, the script scans a directory named `data_to_secure`. You can change the `ROOT_DIRECTORY` variable in the script to point to any directory you wish to scan.
    -   If the specified directory does not exist, the script will create a dummy directory structure with some sample files for demonstration purposes.

2.  **Set the Quantum Anchor**:
    -   Replace the placeholder value of the `QUANTUM_RESISTANT_HASH_ROOT` variable with a real 64-character hexadecimal hash generated from a quantum-seeded source (like the `shake.py` script).

3.  **Execute the Script**:
    ```bash
    python filetagbatch.py
    ```

The script will scan the directory, print the progress, and save the final provenance report to `directory_provenance_report.json`. You can then inspect this JSON file to see the detailed record of all the files and their hashes, all secured under the single quantum anchor.
